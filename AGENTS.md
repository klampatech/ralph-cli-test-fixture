## Build & Run

- Shell scripts in `src/` are directly executable
- Run hello: `./src/hello.sh`
- Run add tests: `./src/add_test.sh`

## Validation

- Tests: `./src/add_test.sh` (shell-based tests)
- No typecheck/lint for shell scripts

## Operational Notes

- This is a shell-script based project
- Functions are sourced via `.` operator
